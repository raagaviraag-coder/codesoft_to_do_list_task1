#  To-Do List Application using Python

##  Project Overview
The To-Do List Application is a simple and useful Python project that helps users manage their daily tasks efficiently. Users can add, update, delete, and view tasks easily through a command-line interface (CLI) or graphical user interface (GUI).

This project is beginner-friendly and helps in understanding Python concepts such as:
- Lists
- Functions
- Loops
- Conditional Statements
- File Handling
- GUI Development (Optional)

---

##  Features
-  Add new tasks
-  View all tasks
-  Update existing tasks
-  Delete completed/unwanted tasks
-  Mark tasks as completed
-  Save tasks permanently using file handling
-  Simple and user-friendly interface

---

##  Technologies Used
- Python 3
- Tkinter (for GUI version)
- File Handling / JSON
